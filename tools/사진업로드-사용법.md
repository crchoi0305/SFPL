# 사진 올리는 방법

사진을 한 번에 여러 장 올리는 방법이 두 가지 있습니다.
둘 중 편한 걸 쓰시면 됩니다.

---

## 방법 1. 폴더 드래그 (설정 불필요, 지금 바로)

1. 올릴 사진들을 **한 폴더에 모아** 둡니다. (원본 그대로 OK — 자동으로 줄여줍니다)
2. 그 폴더를 **`tools/사진앨범추가.bat`** 아이콘 위로 드래그해서 놓습니다.
3. 검은 창이 뜨면 순서대로 입력:
   - **날짜** — `2026.03.14` 형식 (그냥 엔터 = 오늘 날짜)
   - **제목** — 앨범 제목
   - **설명** — 없으면 그냥 엔터
4. 자동 진행: 사진 축소·압축 → `content/photos.json`에 앨범 추가 → GitHub 업로드 → 1~2분 뒤 사이트 반영
5. "완료!" 메시지가 나오면 끝.

- 파일명은 `20260314_01.jpg`, `20260314_02.jpg` … 로 자동 정리됩니다.
- 같은 날짜로 또 올리면 번호가 이어집니다.

**안 될 때**
- "git이 설치되어 있지 않아…" → PC에 Git이 없음. 파일은 로컬에 저장됐으니 알려주세요.
- "git push 실패" → 인터넷 확인 후 `.bat` 다시 실행하면 이어서 됩니다.

---

## 방법 2. Sveltia CMS — 브라우저에서 여러 장 한꺼번에

기존 `/admin` (Decap) 은 사진을 한 장씩만 넣을 수 있습니다.
**Sveltia CMS** 로 바꾸면 미디어 라이브러리에서 여러 장을 한 번에 선택/업로드할 수 있습니다.

### 처음 한 번만: 로그인 준비

주소: **https://crchoi-lab.kr/admin-beta/**

로그인 방법 2가지 중 하나:

**(a) 액세스 토큰 — 가장 간단 (설정 없음)**
1. `/admin-beta/` 접속 → **"액세스 토큰으로 로그인"** 클릭
2. 안내되는 GitHub 링크로 이동 (필요한 권한이 미리 선택돼 있음)
3. 토큰 만료기간 선택 (예: 90일) → **Generate token** → 생성된 토큰 복사
4. `/admin-beta/` 로 돌아와 붙여넣기 → 로그인 완료
   - 토큰은 브라우저에 저장됩니다. 만료되면 3~4번만 다시.

**(b) GitHub 로그인 버튼 — 만료 없음 (초기 설정 필요)**
1. GitHub에서 OAuth App 등록 + Netlify 사이트에 연결
   ([Netlify 공식 가이드](https://docs.netlify.com/manage/security/secure-access-to-sites/oauth-provider-tokens/#git-provider-tokens))
2. 이후 `/admin-beta/` 에서 **"GitHub으로 로그인"** 버튼만 누르면 됨
   - 설정을 도와드릴 수 있습니다.

### 사진 올리기 (로그인 후)

1. **Photos** → 앨범 열기 (또는 새로 만들기)
2. Date / Title / Description 입력
3. **Images** → 이미지 영역 클릭 → 미디어 라이브러리
4. **여러 장을 한 번에 선택** (드래그 업로드도 가능) → 넣기
5. 순서 변경·삭제도 그 자리에서
6. **Publish / Save**

> `/admin-beta/` 가 잘 되면 기존 `/admin/` 도 Sveltia로 바꿔드립니다 (주소는 `/admin/` 유지).
> 그 전까지 `/admin/` 은 기존처럼 계속 쓸 수 있습니다.

## 공통 참고

- 어느 방법이든, 배포 시 서버에서 한 번 더 자동 최적화됩니다
  (`netlify.toml` + `scripts/optimize-images.mjs`).
- 방문자에게는 항상 가볍게(webp) 전송되므로 원본 크기는 신경 안 쓰셔도 됩니다.
