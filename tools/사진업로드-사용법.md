# 사진 올리는 방법

사진을 한 번에 여러 장 올릴 수 있는 방법이 두 가지 있습니다.

---

## 방법 1. 폴더 드래그 (가장 빠름, 권장)

1. 올릴 사진들을 **한 폴더에 모아** 둡니다. (원본 그대로 OK — 자동으로 줄여줍니다)
2. 그 폴더를 **`tools/사진앨범추가.bat`** 아이콘 위로 드래그해서 놓습니다.
3. 검은 창이 뜨면 순서대로 입력:
   - **날짜** — `2026.03.14` 형식 (그냥 엔터 치면 오늘 날짜)
   - **제목** — 앨범 제목
   - **설명** — 없으면 그냥 엔터
4. 자동으로 진행됩니다:
   사진 축소·압축 → `content/photos.json`에 앨범 추가 → GitHub에 업로드 → 1~2분 뒤 사이트 반영
5. "완료!" 메시지가 나오면 끝. 창은 아무 키나 눌러 닫으면 됩니다.

> 사진 파일명은 `20260314_01.jpg`, `20260314_02.jpg` … 로 자동 정리됩니다.
> 같은 날짜로 앨범을 또 올리면 번호가 이어집니다.

**안 될 때**
- "git이 설치되어 있지 않아…" → PC에 Git이 없는 경우. 파일은 로컬에 저장돼 있으니 저에게 알려주시면 올려드립니다.
- "git push 실패" → 인터넷 확인 후 `.bat`을 다시 실행하면 이어서 됩니다.

---

## 방법 2. /admin-beta (브라우저에서, 실험적)

브라우저에서 하고 싶을 때 씁니다.

- 주소: **https://crchoi-lab.kr/admin-beta/**  (기존 `/admin/` 과 로그인 동일)
- Photos → 앨범 열기 → **Images** 항목의 **"＋ 사진 선택"** 버튼 클릭
- 미디어 라이브러리에서 여러 장을 한 번에 선택 (Ctrl/Shift 클릭, 또는 드래그 업로드)
- 썸네일에서 `×` 삭제, `‹ ›` 순서 변경
- 저장하면 기존과 동일하게 반영됩니다

> `/admin-beta/` 는 실험용입니다. 문제가 생기면 기존 **`/admin/`** 을 그대로 쓰시면 됩니다 (전혀 영향 없음).
> 다중 선택이 환경에 따라 한 장씩만 될 수도 있는데, 그때도 버튼만 다시 누르면 되어 기존보다 빠릅니다.

## 참고

- 어느 방법으로 올리든, 배포 시 서버에서 한 번 더 자동 최적화됩니다 (`netlify.toml` + `scripts/optimize-images.mjs`).
- 방문자에게는 항상 가볍게(webp) 전송되므로 원본 크기는 걱정 안 하셔도 됩니다.
